## Summary

**Overview:** This is a comprehensive hackathon blueprint for building a "Digital FTE" (Full-Time Equivalent) — an autonomous AI employee powered by Claude Code and Obsidian that proactively manages personal and business affairs 24/7 using a local-first, human-in-the-loop architecture.

**Key Points:**

- **Architecture:** Four-layer system — Perception (Python Watcher scripts for Gmail, WhatsApp, file system), Reasoning (Claude Code), Action (MCP servers for email, browser, payments), and Persistence (Ralph Wiggum stop-hook loop for autonomous multi-step task completion).

- **Digital FTE Value Proposition:** A Digital FTE works ~8,760 hours/year vs a human's ~2,000, at ~$500-$2,000/month vs $4,000-$8,000+, achieving 85-90% cost savings per task ($0.25-$0.50 vs $3.00-$6.00).

- **Tiered Deliverables:** Bronze (basic vault + 1 watcher), Silver (multiple watchers + MCP + HITL approval workflow), Gold (full cross-domain integration + Odoo accounting + social media + CEO Briefings), Platinum (always-on cloud + local executive with work-zone specialization).

- **Human-in-the-Loop Safety:** Sensitive actions (payments, sends) require file-based approval — Claude writes to /Pending_Approval and only acts when files are moved to /Approved by a human.

- **Security & Ethics:** Credential management via env vars/secrets managers, sandboxing with dry-run flags, comprehensive audit logging, permission boundaries, and responsible automation guidelines including when AI should NOT act autonomously.
